# 火球 M2 至高完整度 Roadmap Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 M1 员工 Alpha 之后，以受控 MVP、公开 V1 和高完整度三个阶段扩展到多市场行情、完整社区、运营、消息、推荐、AI、灾备和长期品控，不用编码绕过数据合同、资质、审核和发布外部依赖。

**Architecture:** 保持模块化单体业务核心与独立行情、异步、实时和 AI 网关；每个波次同时交付 API、Web、App、Admin 与证据。受限能力使用物理隔离域，默认不注册 route/API/navigation/search/deep link。

**Tech Stack:** 延续 M1 基线；新增真实授权数据 adapter、对象存储/媒体流水线、独立搜索与高频实时组件前，必须单独完成 ADR、许可证、安全和容量 Spike。

## Global Constraints

- 本路线不是一周承诺。M2 的 6–8 周、V1 的 4–6 个月、HC 的 9–12 个月以上均从外部准入满足后计算。
- M2 之前没有书面数据权利时继续使用 Synthetic；“网站公开可见”不构成可再分发权。
- 公网 UGC 之前必须有举报、处置、通知、申诉、第二复审、删除传播、审计、急停和值班负责人。
- 真实交易、开户、基金申赎、私募认购、付费荐股、跟单和个性化买卖建议始终是独立持牌项目，不因本路线自动获得授权。
- 每个波次只在前一波 Gate 通过后展开成逐文件实施计划；不得把路线图状态写成“已实现”。

## Wave M2-0: 外部准入 Gate

- [ ] 为每个数据源取得书面合同，逐字段记录采集、存储、展示、缓存、历史、衍生、再分发、地域、终端和终止后的删除权利。
- [ ] 法务批准火球品牌、图标、字体、插画、行情披露、隐私条款、用户协议和风险提示。
- [ ] 指定审核、申诉、隐私、安全、发布、数据供应商和应急值班角色。
- [ ] 准备 Apple/Google 开发者账号、签名证书、真实设备矩阵、域名、WAF/Zero Trust、Secret store 和备份目标。
- [ ] 在 `quality/manifests/m2-entry.json` 记录文件 hash、批准人、有效期和可用环境；任一缺失则 M2 对应能力保持关闭。

成功输出目标：

```text
M2_ENTRY_GATE PASS data_contracts_valid=1 brand_approved=1 governance_staffed=1 release_credentials=1
```

## Wave M2-1: 授权行情与证券资料

- [ ] 为每个获批供应商建立独立 adapter/conformance suite，不把供应商 DTO 暴露给业务域。
- [ ] 实现交易日历、市场时区、盘中/休市/停牌、延迟标识、供应商序列、纠错、修订、entitlement 与降级。
- [ ] 扩展 A 股、港股、美股、指数、基金和 ETF 资料页；每个字段显示来源、as_of 与展示权。
- [ ] 实现供应商断流、部分市场故障、合同到期、数据陈旧和切换演练；无权字段 fail closed。
- [ ] 为真实与 Synthetic adapter 跑同一 conformance suite，对账价格精度、交易日、币种、复权与修订。
- [ ] 通过 `M2_MARKET_GATE` 后才允许移除页面“合成数据”标识；延迟数据仍必须显示延迟和 as_of。

## Wave M2-2: 公网治理与完整社区

- [ ] 在现有 Moderation 上增加申诉、独立第二复审、证据访问审批、留存/删除策略、批量案件和处置 SLA。
- [ ] 增加用户屏蔽、关键词/频率防滥用、设备/账号风险信号、举报滥用保护与未成年人/敏感内容政策。
- [ ] 建设长文草稿/自动保存/预览、视频与图片对象存储、扫描、转码、版权/来源登记和删除传播。
- [ ] 建设创作者中心、内容数据、收藏/关注、话题与频道管理；打赏、付费内容和荐股收益保持不可达。
- [ ] 对 Content/Social/Moderation/Feed/Search/Object Storage/AI Index 做 tombstone 与恢复不复活测试。
- [ ] 进行红队、内容演练和 30 天内部运营试运行；`PUBLIC_UGC_GATE` 通过前公开注册和发布仍关闭。

## Wave M2-3: 提醒、消息和外部 Push

- [ ] 在 canonical Inbox 之上实现事实型 last-price 上穿/下穿提醒，精确定义前值、当前值、去抖、休市、修订和一次触发语义。
- [ ] 增加通知偏好、免打扰、设备 token 所有权、换号撤销、APNS/FCM delivery attempt、重试、退订和失效清理。
- [ ] 构建私信前单独完成反骚扰、屏蔽、举报、证据、限流、未读、删除和隐私影响评估。
- [ ] 运行多设备、离线、换号、撤销、Deep Link、Push 泄露与供应商故障测试。
- [ ] `PUSH_MESSAGING_GATE` 通过前 App 不申请通知权限，API 不接受设备 token。

## Wave M2-4: 组合分析与市场工具

- [ ] 在追加账本上增加外部现金流、公司行动只应用一次、多币种、基准、TWR、回撤与归因；每项先做属性测试和对账基准。
- [ ] 增加自选分组、排序、批量添加、提醒、市场宽度、异动、板块、ETF 关联和基金筛选工具。
- [ ] 所有组合继续默认私有；公开排行、调仓播报、复制或跟单另开法律/产品/风险规格，默认不进入 registry。
- [ ] 对估值 as_of、汇率、公司行动、费用、重放和历史修订建立独立 reconciliation Gate。

## Wave V1-0: 公开发布准备

- [ ] 把模块化单体、行情流水线、SSE/高频实时、对象存储、搜索、队列和数据库部署为可滚动升级的生产拓扑。
- [ ] 建立容量模型、限流、缓存击穿、降级、供应商故障、跨可用区备份、RPO/RTO、恢复演练和发布回滚。
- [ ] 完成 SAST/DAST/SCA、渗透测试、隐私影响评估、数据主体请求、账号注销、导出、删除和审计。
- [ ] 完成 Web WCAG 2.2 AA、iOS/Android screen reader、动态字体、输入法、弱网、低端机和真实设备矩阵。
- [ ] 完成应用商店隐私标签、权限说明、审核账号、内容治理说明、客服/投诉和版本回滚。
- [ ] 连续两个完整开收盘周期、30 天运营、恢复和审核 SLA 达标后，才运行 `PUBLIC_V1_GATE`。

## Wave V1-1: 搜索、推荐与运营成熟

- [ ] 在 PostgreSQL 搜索达到容量边界后，以 ADR 选择独立搜索引擎，双写/回填/切换均支持回滚。
- [ ] 搜索覆盖证券、内容、用户、话题、拼音、别名、联想、热词和安全过滤；相关性评测使用获许可或合成数据。
- [ ] 推荐先从可解释规则与频道运营开始，记录输入、版本、降级和曝光；个性化前完成 consent 与最小化评审。
- [ ] 建设运营位、频道、榜单、活动、公告、实验、急停和审计；运营只能选择结构化白名单卡片。
- [ ] 对冷启动、过滤气泡、违规放大、删除传播和实验污染建立离线/在线评测与回滚门禁。

## Wave HC-0: 有来源 AI 与高完整度平台

- [ ] AI 网关只处理获授权来源和最小必要数据；默认不读取持仓、私信、身份和精确设备信息。
- [ ] 先交付带来源、时点、置信边界和风险提示的摘要/解释；禁止目标价、仓位、个性化买卖和自动写操作。
- [ ] 建立检索权限继承、引用准确性、删除传播、提示注入、越权、幻觉、成本、延迟与模型降级评测。
- [ ] 扩展多市场、全频道、创作者、消息、运营、推荐、灾备和供应商管理，同时维持 CAP 全链追踪。
- [ ] 每季度运行功能总账盘点、依赖/许可证盘点、数据权利复核、权限审计、灾备演练、内容治理演练和 AI 回归。

## 高完整度完成口径

- [ ] 所有目标 CAP 具有唯一 ID、产品 owner、工程 owner、合规处置、页面、状态、触点、API/事件、表、测试和证据。
- [ ] Allowed、FeatureFlagOff、LicensedOnly、Forbidden 在运行 registry 中与批准处置一致。
- [ ] Web/iOS/Android/Admin 对同一能力使用同一契约、领域 ID 和权限语义。
- [ ] 真实数据逐字段可追踪权利、来源、时点、修订和降级；合同失效能自动关闭展示。
- [ ] 公开社区、消息、Push、推荐和 AI 分别通过自己的安全/隐私/治理 Gate。
- [ ] P0/P1 为零、Required 无跳过、恢复与回滚有近期演练证据，才可报告对应阶段 Ready。
